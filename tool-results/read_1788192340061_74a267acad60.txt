   301→   301→
   302→   302→### The "Ugly" Problem
   303→   303→
   304→   304→Previous attempts at this game failed visually because:
   305→   305→- Flat rendering with no depth/perspective
   306→   306→- No parallax — background was static

   312→   312→
   313→   313→### The Solution — Pseudo-3D Perspective Rendering
   314→   314→
   315→   315→Every frame must communicate speed, depth, and life. The rendering approach:
   316→   316→
   317→   317→```kotlin
   318→   318→// Core perspective math — apply to EVERY game object
   319→   319→fun worldToScreen(worldX: Float, worldY: Float, worldZ: Float): ScreenPos {
   320→   320→    val scale = baseScale / (1.0f + worldZ * perspectiveFactor)
   321→   321→    val screenX = vanishingPointX + (worldX - cameraX) * scale
   322→   322→    val screenY = vanishingPointY + (worldY - cameraY) * scale
   323→   323→    return ScreenPos(screenX, screenY, scale)
   324→   324→}
   325→   325→```
   326→   326→
   327→   327→- `perspectiveFactor` controls how quickly objects shrink (tunable in GameConfig)
   328→   328→- `vanishingPointY` at ~38% from top of screen
   329→   329→- All objects are **z-sorted back-to-front** before rendering
   330→   330→- Distant objects get **atmospheric fog** (blend toward sky color)
   331→   331→- Lane width **narrows with distance** (tracks converge to vanishing point)
   332→   332→- Ground plane rendered as **receding trapezoids**
   333→   333→

   376→   376→| Running | Default | 8-frame run cycle (feet sync to ground) | Full |
   377→   377→| Lane Switch | Swipe L/R | Lean + step (4-6 frames, 0.15s) | Full, interpolating X |
   378→   378→| Jumping | Swipe Up | Jump arc (6-8 frames, 0.6s) | Full, elevated Y |
   379→   379→| Sliding | Swipe Down | Roll/duck (6 frames, 0.5s) | 40% height |
   380→   380→| Landing | Jump ends | Squash-stretch (3 frames) | Full |
   381→   381→| Power-up Active | Collect | Glow + modified run | Varies |
   382→   382→| Death | Collision | Crash (8-10 frames) | N/A |
   383→   383→
   384→   384→### Jump Math
   385→   385→```
   386→   386→jumpHeight(t) = jumpStrength * sin(PI * t / jumpDuration)
   387→   387→// jumpDuration: 0.6s, jumpStrength: 4.0 units (tunable)
   388→   388→```
   389→   389→- Parabolic arc with slight hang time at peak
   390→   390→- Landing squash animation
   391→   391→- Jump buffer: 100ms queue for landing
   392→   392→
   393→   393→### Slide Mechanics
   394→   394→- Duration: 0.5s
   395→   395→- Collision box reduces to 40% height
   396→   396→- Roll animation
   397→   397→- Can jump out of slide early
   398→   398→
   399→   399→### Swipe Detection
   400→   400→```
   401→   401→touchDown: record startX, startY, startTime
   402→   402→touchUp:
   403→   403→  dx = endX - startX, dy = endY - startY
   404→   404→  distance = sqrt(dx*dx + dy*dy)
   405→   405→  if distance < 15px: IGNORE
   406→   406→  if dt > 300ms: IGNORE
   407→   407→  if abs(dx) > abs(dy): SWIPE LEFT or RIGHT
   408→   408→  else: SWIPE UP or DOWN
   409→   409→```
   410→   410→- Input latency: <16ms
   411→   411→- One swipe = one action
   412→   412→- Dead zone: 15px
   413→   413→

   431→   431→### Obstacle Pattern System (CRITICAL — NO IMPOSSIBLE COMBINATIONS)
   432→   432→
   433→   433→**IRON RULES:**
   434→   434→1. At least 1 lane MUST always be clear
   435→   435→2. 2-lane obstacles leave exactly 1 safe lane
   436→   436→3. Low obstacles: jumpable path exists
   437→   437→4. High obstacles: slideable path exists
   438→   438→5. Moving trains: 1.5s+ reaction time at current speed
   439→   439→6. Coins guide player toward safe path
   440→   440→7. Never place two same-action obstacles consecutively with <0.5s gap
   441→   441→
   442→   442→**Pattern Examples:**
   443→   443→- EASY: Single train left lane, center+right clear
   444→   444→- MEDIUM: Train left+right, center only option + coin trail leading to center
   445→   445→- HARD: Low barrier center + high barrier left + train approaching right — requires slide center, jump over low barrier, or dodge to right before train arrives
   446→   446→- ADVANCED: Moving train center, requiring timed lane switch through the gap
